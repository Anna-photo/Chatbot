CHATBOT VERSION 7.0 — FIRST CLEAN PROJECT

This folder is a cleaned-up copy of Chatbot Version 6.7.
The original HTML, CSS, and JavaScript content has been preserved; the main change is that the CSS and JavaScript are now separate files so the project can be hosted on GitHub Pages and developed more easily.

FILES
- index.html = the webpage
- style.css = the appearance/design
- chatbot.js = the chatbot behavior and current knowledge/programmed responses
- Chatbot-Version-6.7-BACKUP.htm = untouched backup of the original file

IMPORTANT
Do not delete or rename these files. Keep them in the same folder.
Do not edit chatbot.js yet unless instructed. The next development step is to separate the chatbot's knowledge into its own easy-to-edit knowledge file while preserving the current behavior.

GITHUB PAGES
1. Create a new GitHub repository.
2. Name it something simple such as chatbot.
3. Upload index.html, style.css, chatbot.js, README.txt, and the backup file.
4. Open repository Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Choose Branch: main and Folder: / (root).
7. Save.
8. GitHub will provide the public website address.
